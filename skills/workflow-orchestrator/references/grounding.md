# 검증 규범 상세 (grounding)

> decision-flow.md 「검증 규범 (근거 있는 출력)」의 상세. 집행 문장의 원본은 decision-flow.md이며 본 파일은 실물 문구와 규격만 담는다.

## 고지 문구 실물

- 확인 아이콘 세션 최초 출현 시 (1회): `ℹ️ 표시 안내: 확인 아이콘(✔️)은 셈이나 저장소나 공식 문서로 확인한 사실, 확인 못 함(⚠️)은 판단이 필요한 것입니다. 근거는 "출처 보여줘"로 펼칩니다.`
- 재실행 진행 표시: `⏳ 발언 1건 형식 위반 — 다시 받는 중 (약 1분)`
- 재위반 제외 고지: `⚠️ [페르소나명] 발언 제외 — 형식 재위반. 다음 라운드에 다시 참여합니다.`
- 확인 아이콘 강등 고지: `⚠️ [페르소나명]의 주장 1건을 확인 못 함으로 강등 — 증거 미첨부.`
- 근거 펼치기 머리줄 (메시지 첫 줄, 앞에 문장 없음): `📎 근거 — [가리킨 것]` — 아래는 `- ✔️ [화면 줄 그대로]` 다음 줄 `  ↳ [경로:행 — "인용"]` 짝, 다시 확인한 줄은 `  ↳ 다시 확인 — [증거]`, 끝에 `위 박스에 번호로 답해 주세요`
- 근거 재확인 진행 표시: 재실행 진행 표시 문구를 그대로 쓴다 (`⏳ …`)

## 외부 문서 조사 워커 반환 규격

반환물은 `--- 화면 ---`과 `--- 증거 ---` 두 구획이다. 화면 구획에는 주장별로 `- ✔️ 판정과 주장 1줄`(확인) 또는 `- ⚠️ 판정과 주장 1줄`(반증이나 못 찾음)을 쓰고 주소와 인용을 쓰지 않는다. 증거 구획에는 ✔️ 줄마다 번호 항목 하나 — 첫 줄에 화면 줄을 그대로 반복하고 다음 줄에 `↳ 주소 — "해당 대목 원문 인용"`. 인용이 없는 항목은 본체가 확인 못 함으로 강등한다. 본체의 신뢰 지점은 워커의 판정이 아니라 인용문과 주장의 대조다.

## 소급 반증 형식

이미 지나간 발언을 뒤집는 사실이 나중에 확인되면, 새 메시지에서 대상 발언을 이름으로 가리킨다:
`↳ ✘ 반증 — [출처] 앞선 [페르소나명]의 "[주장 요지]" 주장은 [확인된 사실]로 성립하지 않습니다.`
[출처]는 짧은 이름 — 경로:행과 인용은 쓰지 않는다(증거는 📎 근거로).

## 등급 경계 사례 (결정 스켈레톤)

- 페르소나 라운드 종료 직후의 결정 → 4칸 상시 (빈 칸은 "없음")
- 라운드 없이 저장소 구조 대조로만 묻는 결정 → 문제 칸 + 확인된 사실 칸
- 국면 0 카테고리 확정과 시드 확인 등 로컬 템플릿 결정 → 칸 구성은 기존 템플릿 그대로, 설명 블록은 면제. 「내보내기 전 검사」는 각 항목의 「적용 자리」를 따른다 (선택지 낱말은 모든 박스, 결과 줄은 메뉴형 전부, 선택지 대상은 작업 방향 확인과 단계 감지 둘, 원인은 전 자리, 곁가지는 선택지를 내는 모든 박스)
- 등급 판정 질문("직전에 라운드나 조사가 있었는가")은 박스 칸 수와 설명 블록 요구를 함께 정한다 — "있었다"면 4칸에 더해 **짧은 설명 문단**(이름표 없이), "없었다"면 블록 없음. 다만 사용자가 더 풀어 달라고 하면 등급과 무관하게 블록을 낸다. 로컬 템플릿은 설명 블록만 적용 밖이고 칸 수는 그대로 적용되고, 「내보내기 전 검사」는 각 항목의 「적용 자리」를 따른다

## 관측 연결

- "없음" 칸 3개 연속인 결정이 잦으면 등급 술어 과잉 신호 — tasks/lessons.md에 1줄 기록
- 관측 후 조정 후보 (1차 릴리스 미포함): 결정 근거로 쓰인 ✔️ 주장의 표본 재확인 — 잘못 붙은 ✔️ 통과 사례가 관측되면 추가한다
