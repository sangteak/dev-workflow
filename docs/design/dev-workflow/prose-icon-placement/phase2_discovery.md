## Simplifier 스코프 정리 결과

일부 수용 — 상시 주입본 요약 줄에 아이콘 조항을 더하는 항목만 미룬다. 규범 정본을 읽으라는 지시가 이미 있어 기능적으로 중복이고, 미뤄도 잃는 것이 가장 적다. 판정 표기 정리와 잔존과 도착 검사는 유지한다 — 판정 표기는 사용자가 지적한 바로 그 불편(아이콘만 보면 뜻을 되짚어야 함)의 한 자리이고, 검사는 규범 변경마다 두던 안전망이다. 요구사항 열에서 아홉으로.

## 새로 발견된 미정의 영역과 결정

### 1. 아이콘 이름 부르기와 낱말 대체를 가르는 방법 (결정)

실측이 이 영역을 열었다. 저장소에서 아이콘 바로 뒤에 조사가 붙은 자리는 열두 곳인데 전부 규범 문서가 자기 기호의 뜻을 설명하는 문장이었다. 예를 들어 근거 첨부 의무 조항의 "✔️에는 대조 가능한 증거가 있어야 한다"와 세션 최초 고지 문구의 "✔️는 셈이나 저장소나 공식 문서로 확인한 사실"이 그렇다. 조사 판별만 쓰면 이 정당한 문장들이 위반으로 걸리고 규범이 스스로를 어기게 된다.

**결정: 백틱으로 감싼다.** 아이콘은 줄 첫머리(이름표, 불릿 머리, 판정 이름표)에서 맨몸으로 쓰고, 그 자리를 벗어나 문장 속에서 아이콘 자체를 가리킬 때는 백틱으로 감싼다. 백틱 없는 맨몸 아이콘이 문장 중간에서 조사를 달고 낱말 자리를 차지하면 낱말 대체이고 금지 대상이다. 검사는 예외 목록 없이 모양 하나로 판정한다.

기각한 대안은 자리로 예외를 두는 것이다. 지금 문장을 안 고쳐도 되지만 검사가 자리 목록에 기대고 새 자리가 생기면 놓친다.

### 2. 언어 규범 문장의 실물 (합의)

```
아이콘은 줄 첫머리(이름표, 불릿 머리, 판정 이름표)에서는 맨몸으로 쓴다.
그 자리를 벗어나 문장 속에서 아이콘 자체를 가리킬 때는 백틱으로 감싼다
(예: `✔️`는 확인된 사실을 뜻한다). 백틱 없이 맨몸 아이콘이 문장 중간에서
조사를 달고 낱말 자리를 차지하면 그것이 낱말 대체이며 금지 대상이다.
```

범례처럼 아이콘과 낱말 사이에 공백이 있는 자리(`🔴 높음, 🟡 중간, 🟢 낮음`)는 조사 판별에 걸리지 않는다 — 공백 유무가 이름표와 낱말 대체를 가르는 실제 경계선이다.

### 3. 세션 최초 고지 문구 (합의)

```
ℹ️ 표시 안내: `✔️`는 셈이나 저장소나 공식 문서로 확인한 사실, `⚠️`는 확인 못 해
판단이 필요한 것입니다. 근거는 "출처 보여줘"로 펼칩니다.
```

조사는 백틱 밖에 그대로 붙는다 — 감싸는 대상은 아이콘 자체이지 조사가 아니다.

### 4. Feasibility 판정 발언의 실물 (합의)

```
🏛️ Architect: ⚠️ CAUTION
개발 범위가 넓어 접근 방향 합의가 필요합니다.

🔧 TD: ⚠️ CAUTION
기존 모듈과 결합도가 높아 별도 검토가 필요합니다.

→ 종합 판정: ⚠️ CAUTION
```

이름 줄에 판정 아이콘과 낱말을 함께 쓰고 개행 뒤 근거를 한두 문장으로 둔다. 판정 낱말 병기는 확인 아이콘과 판정 아이콘의 뜻 겹침을 규범을 손대지 않고 없앤다. 종합 판정 줄도 아이콘 슬래시 나열 대신 낱말 병기로 바뀐다.

### 5. Researcher 조사 결과 템플릿의 실물 (합의)

```
[항목명]:
  ✔️ 확인된 사실:
  - [사실 1줄]
  - [사실 1줄]
  우회 가능성: [있음/없음] — [설명 1줄]
  유사 패턴: [발견/미발견] — [설명 1줄]
  결론: [FEASIBLE로 상향 가능 / CAUTION 유지 / RENEGOTIATE 유지]
```

확인된 사실 칸만 이름표 뒤 개행과 불릿으로 내린다. 우회 가능성과 유사 패턴은 한 줄 정형을 유지해 칸 높이가 셋 다 늘어나는 것을 막는다.

### 6. 사후 검사의 대상과 패턴 (합의)

검사는 이 저장소의 규범 문서가 아니라 세션 기록을 훑는다 — 규범 문서는 자기 기호를 설명하므로 훑으면 상시 실패한다. 통과 기준은 소비 프로젝트의 브레인스토밍 한 바퀴다. 위반 패턴은 백틱 없는 맨몸 아이콘에 조사가 바로 붙은 줄이고, 기존 스크립트의 코드 펜스와 인용 줄 제외 틀을 그대로 이어받는다. 이름표 되풀이를 세는 기준은 국면 3으로 넘긴다.

### 7. 동기 대상 자리 (합의)

새로 만들 목록이 없다. 규범 정본의 재서술 지점 목록 열둘이 이미 원본이고, 언어 요약을 실제로 담는 자리 다섯(상시 주입본, orchestrator SKILL, brainstorming SKILL, templates, README)만 건드리면 된다. 상시 주입본은 이번에 미뤘으므로 넷이다.

### 8. 재현 확인 절차 (합의)

새 세션에서는 첫 고지의 아이콘이 백틱으로 감싸져 있는지 본다. 이어 쓰기 세션에서는 재고지가 뜨는 장면에서도 줄 첫머리 라벨 자리에만 맨몸 아이콘이 쓰이는지 보고, Feasibility 판정 화면과 조사 결과 화면이 새 모양으로 나오는지 본다.
