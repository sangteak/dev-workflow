- 🟢 🔍: 언어 규범 펜스 원본은 한 파일뿐(`git grep -l '병렬 나열은 불릿'` 1건). 도착 검사는 펜스 원본 한 곳과 인용 지시문 열한 곳을 따로 센다. 검사 ⑥은 자기 검사라 토큰 비용 0에 가깝다. 요구사항 15(옛 헤더 잔존 패턴)는 A로 대체된 것으로 읽는다

### 스윕(7~13)

### 검사(14~16 + A)
- 🟡 🛠️: A 명령은 Windows git 2.52, msys bash 5.2에서 그대로 돌고 누출 0. HANDOFF 27행이 이름 문구 뒤에 옛 예시를 품어 문구를 지워도 남는다 — 지금 고치거나 완료 검사를 HANDOFF 삭제 뒤에. `-c`는 줄 수. 문구 제거는 두 단계(git grep -n → sed → 세기). 도착 검사는 기존 arrival에 새 헤더 모양을 그대로 넣으면 된다
- 🟡 🔍: 새 헬퍼는 별개 함수, 기존 arrival과 residue는 건드리지 않는다. 도착 검사에 "문구가 규범 줄에 1건 이상". 검사 0건은 규범 실패만 잡고 복구 실패는 D로
- 🟡 🎯: 새 헤더 도착 검사 셋의 원문이 다르다(decision-flow 50행 `확정 N/M`, context-handling 84행 `확정 [N]/[M]`, bootstrap 36행은 "진행 중:" 없음) — 패턴을 파일별로, bootstrap은 낱말 추가 허용 명시. 포함 목록에 svg 없음. test-restatements.sh와 test-completion-nudge.sh의 ·는 전부 주석

### B 대조와 고정표
- 🟡 🛠️: 지우고 비교하면 "결과 보고·확인"→"결 보고, 확인" 훼손이 통과(시제품 실측). 방향 있는 차이로 — 옛 쪽에만 남는 글자는 ·뿐, 새 쪽에만 남는 글자는 쉼표, 공백, 개행, 불릿 접두, 와, 과뿐, 새 조사 수 ≤ 지운 · 수. CR 제거. node 24와 python 3.13 있음, jq 없음. 고정표는 "그대로 옮기라고 주는 값"이라 예시 교훈과 충돌하지 않음
- 🟡 🔍: 조사 오선택, 묶음 경계 이동("A와 B, C" vs "A, B와 C"), 주어 목적어 바꿈이 통과 — 리뷰 항목 추가, 재배치 hunk는 필독 표시, `git diff -U0`
- 🟡 🎯: 허용 연산에 "나/이나" 없음이 R1 ③의 뿌리. 고정표 후보 추가(268행과 429행, 355~357행, bootstrap 36행 괄호 구조, 172행 검증 결과 줄). 표 칸 안 항목에 쉼표가 든 자리는 실측에서 못 찾음

7. 실사용 스크립트 — 세션 파일 인자, subagents/ 함께, 출처 열, node, `tests/hooks/` 밖, K=0 허용
8. 워커 규칙 — Edit만, `git diff --stat` 대조, 층 판정 파일 여섯은 researcher, 나머지 grunt, 리뷰 항목에 "와/과 마지막 한 번"과 "받침"
