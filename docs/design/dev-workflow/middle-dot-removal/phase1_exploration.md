## 확정된 작업 방향

- `action: spec-change` — 근거: 언어 규범 펜스(decision-flow 271행 "병렬 나열은 불릿으로")와 되물음 꼬리표 규칙(360행 "둘 이상이면 `·`로 잇는다")이 이미 있어 고칠 대상이 있고, 화면 문면이 바뀌는 겉보기 동작 변경이라 리팩터링이 아니다.

## 종료 조건 충족 내역 (spec-change: 「무엇이 어떻게 바뀌는가」)

- 무엇이: 언어 규범의 나열 규칙과, 그 규범을 재서술하는 모든 문서의 나열 문체
- 어떻게: 가운뎃점(·)을 어디에도 쓰지 않는다. 문장 안 나열은 쉼표와 "와/과", 층이 있으면 줄을 나눠 불릿, 표 칸과 한 줄 표시는 쉼표, 항목 안에 쉼표가 들면 어순 재배치. 규칙 한 줄이 아니라 저장소 스윕과 상시 잔존 검사가 실체다.

## 탐색된 요구사항 전체 목록

### 규범
1. 언어 규범 펜스에 가운뎃점 금지 줄 하나와 올바른 문장 예시 하나를 병기한다. 예시는 워커 프롬프트 열한 곳에 펜스 전문으로 복사되어 따라 쓰는 본이 된다
2. 규칙 문장: 문장 안 나열은 쉼표와 "와/과". 층이 있으면(항목이 쉼표, 따옴표, 줄표를 품거나 나열이 두 층) 줄을 나눠 불릿. 표 칸과 커밋 제목과 한 줄 표시처럼 줄을 못 나누는 자리는 쉼표. 항목 안에 쉼표가 들면 어순을 바꿔 없앤다. "그리고"는 층 나누기에 쓰지 않는다
3. 결정 박스 꼬리표는 앞은 쉼표, 마지막만 "와/과" — `(다시 씀: 낱말 풀이, 왜 문제인지와 고르면 어떻게 되는지)`. 360행 규칙 교체
4. 한 줄 표시 셋은 쉼표로 이은 한 줄 — 결정 진행 헤더 `📋 확정 N/M, 진행 중: [결정명], 다시 볼 것 K건`, 첫 질문 안내줄, 검증 결과 줄 `✅ PASS: N, ⚠️ PARTIAL: N, ❌ FAIL: N`. 이름표 없는 칸(context-handling 116행 "자리: … · N개 · …")은 이름표를 붙인다
5. 「내보내기 전 검사」에 여섯째 항목 "가운뎃점 0개"를 더한다. 별도 호출과 재생성 없음 — 이미 써 둔 문장을 다시 보는 검사다
6. bootstrap에는 짧은 조각만. 36행 폴백 한 줄(·가 열둘)은 불릿으로 풀어 쓴다. 8행의 두 층 나열은 21~25행 표를 가리키는 한 줄로 줄인다. 줄 수 상한 없음

### 스윕
7. 범위: 모델이 읽는 것 전부(skills, commands, hooks 주입 문구, README, CLAUDE.md, tasks/lessons.md, tests, scripts)와 docs/design의 도메인 문서와 설계 문서
8. 면제는 경로 셋뿐 — phase 파일, `_archive/`, `evidence/`. 구문(펜스, 인용 블록, 백틱) 면제는 두지 않는다. skills 펜스 안 57개는 살아 있는 템플릿이라 전수 검사 대상
9. 설계 문서 안 옛 화면 인용 29개(code-name-lookup 3, reask-reassembly 1, reask-cases-all 25)는 `evidence/`로 옮기거나 행 번호 참조로 바꾼다
10. README의 화면 견본(363행, 113행 등)은 전부 새 모양으로
11. lessons.md는 예외 없이 전부 고쳐 쓴다 (·가 든 줄 39개, 옛 화면 인용 없음)
12. 검사 스크립트 넷(test-restatements.sh, check-restatements, sweep, bump-version)과 test-completion-nudge.sh의 주석과 고정 문구도 고친다
13. 재서술 지점 열둘 갱신과 도착 문면 확인은 기존 관행대로

### 검사
14. `tests/hooks/test-restatements.sh`에 재귀 걷기 헬퍼 신설 — 저장소를 걷되 경로 셋을 제외하고, "가운뎃점(·)"을 이름으로 부르는 줄 목록만 빼고 센다. 패턴은 바이트 이스케이프 `$'\xc2\xb7'`로 적어 스크립트 자신이 0건을 유지한다. `-I`로 바이너리 제외
15. 옛 헤더 모양(`확정 N/M ·`)을 잔존 패턴으로 등록한다
16. `scripts/sweep`은 손대지 않는다 (범위 고정 교훈). 판정은 test-restatements.sh가 한다

### 기록
17. 3절 요구사항 행에 bootstrap 대상 행, 9절 검증 표에 "38행 6,562바이트 → N행 M바이트" 한 행, `hooks/session-start` 4행 주석("~2.5KB")을 실측으로 갱신
