# perforce-search-ignore Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Perforce 저장소에서 `/dev-workflow:search-ignore` 명령 하나로 세션 폴더의 `.p4ignore` 폴더 줄을 확인받아 `.claude/ignore.yaml`에 기록하고, 그 yaml에서 `.ignore`를 만들어 Claude Code Grep 검색에서 빌드 산출물 폴더를 뺀다.

**Architecture:** 판단이 필요한 계산(파싱, 디스크 대조, 미리 체크, 포함 판정, 파일 쓰기, 확인용 파일 고르기)은 모두 TypeScript 스크립트가 하고, esbuild로 `mcp/dist/search-ignore.js` 한 파일에 묶는다(MCP 서버 `mcp/dist/index.js`와 별개 파일, `mcp/`의 빌드 설정만 빌림). 명령 문서 `commands/search-ignore.md`는 스크립트를 Bash로 두 번(`plan`, `apply`) 부르고, 후보 화면과 Grep 확인만 모델이 한다.

**Tech Stack:** TypeScript, Node.js 18+ (`--target=node18`, CJS), esbuild 0.25, `yaml` 2.x (번들 안), `node:test`, Claude Code 명령 문서(Markdown).

**Spec:** `docs/design/dev-workflow/perforce-search-ignore/perforce-search-ignore.md` (결정 이력: 같은 폴더 `phase1_exploration.md`, `phase2_discovery.md`, `phase3_validation.md` — 뒤 국면이 우선)

## Global Constraints

- Node 18에서 돌아야 한다. Node 20+ 전용 API(`path.matchesGlob`, `fs.globSync` 등)를 쓰지 않는다. 이 PC는 Node 24라서 로컬 테스트는 통과해도 18에서 깨질 수 있으니, 소스에 `matchesGlob`, `globSync` 문자열이 없는지 테스트로 막는다.
- 스크립트 원본은 MCP 서버 모듈(`src/index.ts`, `src/digest.ts`, `src/verify.ts`, `src/checkpoint.ts`, `@modelcontextprotocol/sdk`, `zod`)을 import하지 않는다.
- `.ignore` 줄은 `.p4ignore`에서 고른 줄과 user 부분 줄을 **그대로** 옮긴다. `**/`를 붙이거나 모양을 바꾸지 않는다.
- 같은 입력이면 같은 출력(바이트 단위). `.ignore` 머리에 생성 시각이나 해시를 넣지 않는다.
- `.ignore` 머리 3줄은 정확히:
  - `# generated by /dev-workflow:search-ignore — do not edit`
  - `# 직접 고치면 다음 실행 때 사라집니다. .claude/ignore.yaml의 user 부분을 고친 뒤 /dev-workflow:search-ignore를 다시 실행하세요`
  - `# source: <실제 원본 이름>` (`.p4ignore` 또는 `p4ignore.txt`)
- 소유 표지 판별: BOM과 CR을 걷은 첫 줄이 `# generated by /dev-workflow:search-ignore`로 시작하는가.
- 좁은 산출물 이름 9개(소문자 비교): `intermediate`, `deriveddatacache`, `saved`, `binaries`, `node_modules`, `__pycache__`, `.gradle`, `.venv`, `venv`. `build`는 넣지 않는다.
- 세션 폴더에 `.p4ignore`, 없으면 `p4ignore.txt`. 둘 다 없으면 멈춤 문구: "`.p4ignore`가 있는 폴더에서 세션을 여세요". 위로 올라가며 찾지 않는다. `p4`와 git을 부르지 않는다.
- 명령은 사용자 설정 파일(`settings.json`, `settings.local.json`)을 고치지 않는다.
- 스크립트 호출은 Bash 도구로만 한다(PowerShell 금지 — Node 없음 종료 코드 127 판별).
- 사용자 대면 문구는 한국어, 가운뎃점(·) 금지, 나열은 쉼표와 "와/과".
- 커밋은 기능 브랜치에서 태스크마다 한다. main 머지와 푸시는 Completion Protocol에서 사용자 확인 뒤에만 한다.

`mcp/src/search-ignore/match.ts`:
```ts
/** 폴더 줄 패턴 — .ignore(gitignore) 규칙대로 한 조각 줄은 어느 깊이든, 가운데나 앞 / 줄은 세션 폴더 기준. */
export interface FolderPattern {
  raw: string;
  segments: string[];
  anchored: boolean;
}

/** 폴더 줄이 아니면 null, 이 명령이 다루지 않는 모양이면 "unsupported". */
export function parseFolderPattern(raw: string): FolderPattern | "unsupported" | null {
  let body: string;
  if (raw.endsWith("/**")) body = raw.slice(0, -3);
  else if (raw.endsWith("/")) body = raw.slice(0, -1);
  else return null;
  let anchored = false;
  if (body.startsWith("/")) {
    anchored = true;
    body = body.slice(1);
  }
  if (body === "" || /[?[\]]/.test(body) || body.includes("**")) return "unsupported";
  const segments = body.split("/");
  if (segments.some((s) => s === "")) return "unsupported";
  if (segments.length > 1) anchored = true;
  return { raw, segments, anchored };
}

export function segmentMatches(seg: string, name: string, caseInsensitive: boolean): boolean {
  const re = "^" + seg.split("*").map((p) => p.replace(/[.+^${}()|\\]/g, "\\$&")).join("[^/]*") + "$";
  return new RegExp(re, caseInsensitive ? "i" : "").test(name);
}
```

`mcp/src/search-ignore/p4ignore.ts`:
```ts
import { FolderPattern, parseFolderPattern } from "./match";

export interface ParsedP4Ignore {
  folders: FolderPattern[];
  unsupported: string[];
}

export function stripBom(text: string): string {
  return text.charCodeAt(0) === 0xfeff ? text.slice(1) : text;
}

/** 주석, 빈 줄, ! 줄, 파일 줄을 빼고 폴더 줄만 등장 순서대로(중복 제거) 돌려준다. */
export function parseP4Ignore(text: string): ParsedP4Ignore {
  const folders: FolderPattern[] = [];
  const unsupported: string[] = [];
  const seen = new Set<string>();
  for (const rawLine of stripBom(text).split(/\r?\n/)) {
    const line = rawLine.trim();
    if (line === "" || line.startsWith("#") || line.startsWith("!")) continue;
    if (seen.has(line)) continue;
    const p = parseFolderPattern(line);
    if (p === null) continue;
    seen.add(line);
    if (p === "unsupported") unsupported.push(line);
    else folders.push(p);
  }
  return { folders, unsupported };
}
```

```ts
import * as fs from "node:fs";
import * as path from "node:path";
import { FolderPattern, segmentMatches } from "./match";

export interface PatternMatch {
  pattern: FolderPattern;
  paths: string[];
  caseOnly: string[];
}

function subdirs(abs: string): string[] {
  try {
    return fs
      .readdirSync(abs, { withFileTypes: true })
      .filter((e) => e.isDirectory() && !e.isSymbolicLink())
      .map((e) => e.name)
      .sort();
  } catch {
    return [];
  }
}

function expandAnchored(root: string, p: FolderPattern): { paths: string[]; caseOnly: string[] } {
  let cur: string[] = [""];
  for (const seg of p.segments) {
    const next: string[] = [];
    for (const rel of cur) {
      for (const name of subdirs(path.join(root, rel))) {
        if (segmentMatches(seg, name, true)) next.push(rel === "" ? name : `${rel}/${name}`);
      }
    }
    cur = next;
  }
  const paths: string[] = [];
  const caseOnly: string[] = [];
  for (const rel of cur) {
    const names = rel.split("/");
    const exact = p.segments.every((seg, i) => segmentMatches(seg, names[i], false));
    (exact ? paths : caseOnly).push(rel);
  }
  return { paths: paths.sort(), caseOnly: caseOnly.sort() };
}

export function scanPatterns(root: string, patterns: FolderPattern[]): PatternMatch[] {
  const results = patterns.map((pattern) => ({ pattern, paths: [] as string[], caseOnly: [] as string[] }));
  const single = results.filter((r) => !r.pattern.anchored);
  for (const r of results) {
    if (r.pattern.anchored) Object.assign(r, expandAnchored(root, r.pattern));
  }
  if (single.length > 0) {
    const queue: string[] = [""];
    while (queue.length > 0) {
      const rel = queue.shift() as string;
      for (const name of subdirs(path.join(root, rel))) {
        if (name === ".git") continue;
        const child = rel === "" ? name : `${rel}/${name}`;
        let stop = false;
        for (const r of single) {
          const seg = r.pattern.segments[0];
          if (segmentMatches(seg, name, false)) {
            r.paths.push(child);
            stop = true;
          } else if (segmentMatches(seg, name, true)) {
            r.caseOnly.push(child);
            stop = true;
          }
        }
        if (!stop) queue.push(child);
      }
    }
    for (const r of single) {
      r.paths.sort();
      r.caseOnly.sort();
    }
  }
  return results;
}
```

```ts
import { segmentMatches } from "./match";
import { PatternMatch } from "./scan";

export const ARTIFACT_NAMES: readonly string[] = [
  "intermediate", "deriveddatacache", "saved", "binaries", "node_modules", "__pycache__", ".gradle", ".venv", "venv",
];

export interface Row {
  no: number;
  line: string;
  matchCount: number;
  preselected: boolean;
  includedBy: string | null;
}

function lastSegment(rel: string): string {
  const parts = rel.split("/");
  return parts[parts.length - 1];
}

export function buildRows(matches: PatternMatch[], previousSystem: string[] | null): Row[] {
  const present = matches.filter((m) => m.paths.length > 0);
  const rows: Row[] = present.map((m, i) => ({
    no: i + 1,
    line: m.pattern.raw,
    matchCount: m.paths.length,
    preselected:
      previousSystem === null
        ? m.paths.some((p) => ARTIFACT_NAMES.includes(lastSegment(p).toLowerCase()))
        : previousSystem.includes(m.pattern.raw),
    includedBy: null,
  }));
  const coveringRows = present
    .map((m, i) => ({ m, row: rows[i] }))
    .filter((x) => x.row.preselected && !x.m.pattern.anchored);
  present.forEach((m, i) => {
    if (rows[i].preselected) return;
    const cover = coveringRows.find((c) =>
      m.paths.every((p) => p.split("/").some((seg) => segmentMatches(c.m.pattern.segments[0], seg, false))),
    );
    if (cover) rows[i].includedBy = cover.row.line;
  });
  return rows;
}
```

```ts
import { parseDocument } from "yaml";
import { stripBom } from "./p4ignore";

export const SYS_START = "# >>> search-ignore system (명령이 다시 씀 — 직접 고치지 마세요)";
export const SYS_END = "# <<< search-ignore system";

export class StopError extends Error {
  constructor(public reason: string, message: string) {
    super(message);
  }
}

export interface YamlSource {
  system: string[];
  user: string[];
}

function stringList(v: unknown, where: string): string[] {
  if (v === undefined || v === null) return [];
  if (!Array.isArray(v) || v.some((x) => typeof x !== "string")) {
    throw new StopError("yaml-error", `.claude/ignore.yaml의 ${where}.exclude는 문자열 목록이어야 합니다. 파일은 바꾸지 않았습니다.`);
  }
  return v as string[];
}

export function readYamlSource(text: string): YamlSource {
  const doc = parseDocument(stripBom(text));
  if (doc.errors.length > 0) {
    throw new StopError("yaml-error", `.claude/ignore.yaml을 읽지 못했습니다: ${doc.errors[0].message.split("\n")[0]}. 파일은 바꾸지 않았습니다.`);
  }
  let js: unknown;
  try {
    js = doc.toJS();
  } catch (e) {
    throw new StopError(
      "yaml-error",
      `.claude/ignore.yaml을 읽지 못했습니다: ${(e as Error).message}. user 부분에서 * 나 ! 로 시작하는 줄은 따옴표로 감싸세요. 파일은 바꾸지 않았습니다.`,
    );
  }
  const obj = (js ?? {}) as { system?: { exclude?: unknown }; user?: { exclude?: unknown } };
  return { system: stringList(obj.system?.exclude, "system"), user: stringList(obj.user?.exclude, "user") };
}

function systemBlock(system: string[], eol: string): string {
  const lines = [SYS_START, "system:"];
  if (system.length === 0) lines.push("  exclude: []");
  else {
    lines.push("  exclude:");
    for (const s of system) lines.push(`    - ${JSON.stringify(s)}`);
  }
  lines.push(SYS_END);
  return lines.join(eol);
}

export function renderInitialYaml(system: string[]): string {
  return [
    "# /dev-workflow:search-ignore 원본 — .ignore는 이 파일에서 만들어집니다",
    systemBlock(system, "\n"),
    "user:",
    '  # 검색에서 더 뺄 폴더를 적고 /dev-workflow:search-ignore 를 다시 실행하세요. 예: - "Temp/"',
    "  # 적는 모양은 .p4ignore 줄과 같습니다. 가운데 / 가 든 줄은 이 폴더 기준이고, 어느 깊이든 빼려면 앞에 **/ 를 붙입니다.",
    "  # * 나 ! 로 시작하는 줄은 따옴표로 감쌉니다.",
    "  # 그만 쓰려면 이 파일과 .ignore를 지웁니다.",
    "  exclude: []",
    "",
  ].join("\n");
}

export function replaceSystem(text: string, system: string[]): string {
  const bom = text.charCodeAt(0) === 0xfeff ? "\uFEFF" : "";
  const body = stripBom(text);
  const eol = body.includes("\r\n") ? "\r\n" : "\n";
  const lines = body.split(/\r?\n/);
  const starts = lines.flatMap((l, i) => (l.trimEnd() === SYS_START ? [i] : []));
  const ends = lines.flatMap((l, i) => (l.trimEnd() === SYS_END ? [i] : []));
  if (starts.length !== 1 || ends.length !== 1 || starts[0] > ends[0]) {
    throw new StopError(
      "marker-error",
      ".claude/ignore.yaml의 system 구획 표지가 한 쌍이 아닙니다. 표지 줄을 되돌리거나 파일을 지운 뒤 다시 실행하세요. 파일은 바꾸지 않았습니다.",
    );
  }
  const out = [...lines.slice(0, starts[0]), systemBlock(system, eol), ...lines.slice(ends[0] + 1)].join(eol);
  const check = readYamlSource(out);
  if (JSON.stringify(check.system) !== JSON.stringify(system)) {
    throw new StopError("marker-error", ".claude/ignore.yaml system 구획을 다시 쓴 결과가 맞지 않습니다. 파일은 바꾸지 않았습니다.");
  }
  return bom + out;
}
```

```ts
import { stripBom } from "./p4ignore";

export const OWNER_PREFIX = "# generated by /dev-workflow:search-ignore";

export function isOwned(text: string): boolean {
  const first = stripBom(text).split(/\r?\n/)[0] ?? "";
  return first.startsWith(OWNER_PREFIX);
}

export function renderIgnore(sourceName: string, system: string[], user: string[]): string {
  const head = [
    `${OWNER_PREFIX} — do not edit`,
    "# 직접 고치면 다음 실행 때 사라집니다. .claude/ignore.yaml의 user 부분을 고친 뒤 /dev-workflow:search-ignore를 다시 실행하세요",
    `# source: ${sourceName}`,
  ];
  const seen = new Set(system);
  const extra: string[] = [];
  for (const u of user) {
    if (!seen.has(u)) {
      seen.add(u);
      extra.push(u);
    }
  }
  return [...head, ...system, ...extra, ""].join("\n");
}
```

```ts
import * as fs from "node:fs";
import * as path from "node:path";

export interface ProbePick {
  file: string;
  text: string;
}

const MAX_FILES = 2000;
const SPECIAL = /[.*+?()[\]{}|\\^$]/;

function pickLine(abs: string): string | null {
  let buf: Buffer;
  try {
    const st = fs.statSync(abs);
    if (st.size > 1024 * 1024) return null;
    buf = fs.readFileSync(abs);
  } catch {
    return null;
  }
  if (buf.subarray(0, 65536).includes(0)) return null;
  for (const raw of buf.toString("utf8").split(/\r?\n/)) {
    const line = raw.trim();
    if (line.length >= 24 && line.length <= 200 && !SPECIAL.test(line)) return line;
  }
  return null;
}

export function pickProbe(root: string, relFolder: string): ProbePick | null {
  const queue: string[] = [relFolder];
  let seen = 0;
  while (queue.length > 0 && seen < MAX_FILES) {
    const rel = queue.shift() as string;
    let entries: fs.Dirent[];
    try {
      entries = fs.readdirSync(path.join(root, rel), { withFileTypes: true }).sort((a, b) => a.name.localeCompare(b.name));
    } catch {
      continue;
    }
    for (const e of entries) {
      const child = `${rel}/${e.name}`;
      if (e.isSymbolicLink()) continue;
      if (e.isDirectory()) queue.push(child);
      else if (e.isFile()) {
        seen++;
        const text = pickLine(path.join(root, child));
        if (text !== null) return { file: child, text };
        if (seen >= MAX_FILES) break;
      }
    }
  }
  return null;
}
```

```ts
    throw new StopError(
      "foreign-ignore",
      "이 폴더에는 이 명령이 만들지 않은 .ignore가 있습니다. 기존 .ignore를 지우거나 이름을 바꾼 뒤 다시 실행하세요. 남길 줄은 그 전에 적어 두었다가 .claude/ignore.yaml의 user 부분에 옮기세요.",
    );
  }
  const yamlText = readIf(path.join(root, YAML_REL));
  const yaml = yamlText === null ? null : readYamlSource(yamlText);
  const parsed = parseP4Ignore(srcText);
  const matches = scanPatterns(root, parsed.folders);
  const rows = buildRows(matches, yaml ? yaml.system : null);
  const firstPaths = new Map(matches.map((m) => [m.pattern.raw, m.paths]));
  const caseOnly = matches.filter((m) => m.caseOnly.length > 0).map((m) => ({ line: m.pattern.raw, paths: m.caseOnly }));
  const notices: string[] = [];
  if (fs.existsSync(path.join(root, ".rgignore"))) {
    notices.push("세션 폴더에 .rgignore가 있어 .ignore보다 앞섭니다. 제외가 먹지 않으면 먼저 확인하세요.");
  }
  const digest = crypto
    .createHash("sha256")
    .update(JSON.stringify({ src: srcText, yaml: yamlText ?? "", rows: rows.map((r) => [r.line, r.matchCount]) }))
    .digest("hex")
    .slice(0, 16);
  return { source, srcText, yamlText, yaml, rows, firstPaths, caseOnly, unsupported: parsed.unsupported, notices, digest };
}

function renderScreen(p: Prepared): string {
  const out: string[] = [];
  if (p.rows.length === 0) out.push(`${p.source} 폴더 줄 가운데 디스크에 있는 것이 없습니다.`);
  else {
    out.push(`${p.source} 폴더 줄 가운데 디스크에 있는 것 (${p.rows.length}행)`, "");
    for (const r of p.rows) {
      const tail = r.includedBy ? `(체크된 \`${r.includedBy}\`에 포함)` : `(폴더 ${r.matchCount}곳)`;
      out.push(`  [${r.preselected ? "x" : " "}] ${r.no}. ${r.line}  ${tail}`);
    }
  }
  out.push("");
  for (const c of p.caseOnly) {
    out.push(`대소문자만 다른 폴더: \`${c.line}\` ↔ ${c.paths.join(", ")} — .ignore는 대소문자를 가려서 이 줄은 먹지 않습니다.`);
  }
  if (p.unsupported.length > 0) out.push(`이 명령이 다루지 않는 모양이라 뺀 줄: ${p.unsupported.map((u) => `\`${u}\``).join(", ")}`);
  out.push(`${p.source}에 없는 폴더는 .claude/ignore.yaml의 user 부분에 적고 다시 실행하세요.`);
  return out.join("\n");
}

export function runPlan(root: string): PlanResult {
  const p = prepare(root);
  return {
    status: "ok",
    source: p.source,
    digest: p.digest,
    rows: p.rows,
    caseOnly: p.caseOnly,
    unsupported: p.unsupported,
    notices: p.notices,
    screen: renderScreen(p),
  };
}

function writeAtomic(root: string, rel: string, text: string, written: string[]): void {
  const abs = path.join(root, rel);
  if (readIf(abs) === text) return;
  fs.mkdirSync(path.dirname(abs), { recursive: true });
  const tmp = `${abs}.tmp-${process.pid}`;
  fs.writeFileSync(tmp, text);
  fs.renameSync(tmp, abs);
  written.push(rel);
}

function probeFor(root: string, kind: "system" | "user", line: string, folders: string[]): Probe {
  if (folders.length === 0) return { kind, line, unverifiable: true, why: "맞는 폴더가 디스크에 없음" };
  for (const folder of folders) {
    const pick = pickProbe(root, folder);
    if (pick) return { kind, line, folder, file: pick.file, text: pick.text };
  }
  return { kind, line, unverifiable: true, why: "고를 텍스트 파일이 없음" };
}

export function runApply(root: string, rowNos: number[], digest: string): ApplyResult {
  const p = prepare(root);
  if (p.digest !== digest) {
    throw new StopError(
      "digest-mismatch",
      "후보를 계산한 뒤 .p4ignore, .claude/ignore.yaml이나 폴더가 바뀌었습니다. 명령을 다시 실행하세요. 파일은 바꾸지 않았습니다.",
    );
  }
  for (const n of rowNos) {
    if (!p.rows.some((r) => r.no === n)) {
      throw new StopError("bad-rows", `행 번호 ${n}은 후보에 없습니다. 파일은 바꾸지 않았습니다.`);
    }
  }
  const chosen = p.rows.filter((r) => rowNos.includes(r.no));
  const system = chosen.map((r) => r.line);
  const user = p.yaml ? p.yaml.user : [];
  const yamlOut = p.yamlText === null ? renderInitialYaml(system) : replaceSystem(p.yamlText, system);
  const ignoreOut = renderIgnore(p.source, system, user);
  const written: string[] = [];
  writeAtomic(root, YAML_REL, yamlOut, written);
  writeAtomic(root, ".ignore", ignoreOut, written);

  const probes: Probe[] = [];
  if (chosen.length > 0) {
    let sys: Probe | null = null;
    for (const r of chosen) {
      const pr = probeFor(root, "system", r.line, p.firstPaths.get(r.line) ?? []);
      if (!("unverifiable" in pr)) {
        sys = pr;
        break;
      }
      sys = sys ?? pr;
    }
    if (sys) probes.push(sys);
  }
  const userPatterns = user
    .filter((u) => !system.includes(u))
    .map((u) => parseFolderPattern(u))
    .filter((x): x is FolderPattern => x !== null && x !== "unsupported");
  if (user.length > 0) {
    const matches = scanPatterns(root, userPatterns);
    const hit = matches.find((m) => m.paths.length > 0);
    probes.push(hit ? probeFor(root, "user", hit.pattern.raw, hit.paths) : { kind: "user", line: user[0], unverifiable: true, why: "맞는 폴더가 디스크에 없음" });
  }
  return { status: "ok", written, system, user, probes, notices: p.notices };
}

function arg(argv: string[], name: string): string | undefined {
  const i = argv.indexOf(name);
  return i >= 0 ? argv[i + 1] : undefined;
}

export function main(argv: string[]): number {
  const out = (o: unknown) => process.stdout.write(JSON.stringify(o) + "\n");
  try {
    if (argv[0] === "--version") {
      out({ status: "ok", version: "1" });
      return 0;
    }
    const root = arg(argv, "--root");
    if (!root || (argv[0] !== "plan" && argv[0] !== "apply")) {
      out({ status: "error", message: "usage: plan --root <dir> | apply --root <dir> --rows <1,2> --digest <hex>" });
      return 1;
    }
    if (argv[0] === "plan") out(runPlan(root));
    else {
      const rowsArg = arg(argv, "--rows") ?? "";
      const rows = rowsArg.trim() === "" ? [] : rowsArg.split(",").map((s) => Number(s.trim()));
      out(runApply(root, rows, arg(argv, "--digest") ?? ""));
    }
    return 0;
  } catch (e) {
    if (e instanceof StopError) {
      out({ status: "stop", reason: e.reason, message: e.message });
      return 2;
    }
    out({ status: "error", message: (e as Error).message });
    return 1;
  }
}
```

````markdown
# /dev-workflow:search-ignore

세션 폴더의 `.p4ignore`(없으면 `p4ignore.txt`) 폴더 줄을 후보로 확인받아 `.claude/ignore.yaml`에 기록하고, 그 yaml에서 `.ignore`를 만든다. 계산과 파일 쓰기는 모두 스크립트가 한다. 이 문서의 모델 몫은 화면, 사용자 응답 받기, Grep 확인뿐이다.

## 규칙

- 스크립트는 **Bash 도구로만** 부른다. 경로는 아래 줄을 글자 그대로 쓴다(치환된 절대 경로). `<ROOT>`에는 이 세션의 작업 폴더(환경 정보의 Primary working directory) 절대 경로를 넣는다. Bash의 현재 폴더를 쓰지 않는다.
- 스크립트가 실패하면 모델이 `.ignore`나 yaml을 대신 쓰지 않는다.
- 스크립트 출력의 `message`와 `screen`은 고쳐 쓰지 않고 그대로 보인다.

## 4. Grep 확인

`probes`의 항목마다 순서대로 한다.

- `unverifiable: true`인 항목: "확인 못 함 — `<line>`: `<why>`"로 보고한다.
- 그 밖의 항목은 두 번 부른다.
  1. 양성 대조 — 이 호출만 `path`를 준다: Grep `pattern: <text>`, `path: <ROOT>/<folder>`, `output_mode: files_with_matches`, `head_limit: 0`. (`text`에는 정규식 특수문자가 없으므로 그대로 패턴으로 쓴다.) 결과에 `<file>`이 없으면 "확인 못 함 — `<line>`: 문자열을 찾지 못함"으로 보고하고 다음 항목으로 간다.
  2. 본 확인 — Grep `pattern: <text>`, `output_mode: files_with_matches`, `head_limit: 0`만 준다. `path`, `glob`, `type`은 비운다.
  - 본 확인 결과에 `<file>`이 **없으면** 통과, **있으면** 실패다. 결과 건수로 판단하지 않는다.
  - 시간 초과로 결과가 없으면 통과가 아니다: "시간 초과 — 제외가 먹는지 판단하지 못함"으로 보고한다.
- 실패면: "제외 실패 — `<line>`" 뒤에 원인 후보를 붙인다: `notices`의 `.rgignore` 알림, 하위 폴더에 따로 있는 `.ignore`나 `.rgignore`. 만든 파일은 그대로 둔다.
````
